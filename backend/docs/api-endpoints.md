# Starter endpoints

- `GET /api/health` — health check
- `POST /api/sos/` — demo SOS creation; no persistence/dispatch
- `POST /api/responders/{responder_id}/location` — demo location payload; not persisted
- `GET /api/responders/nearby` — placeholder
- `POST /api/contacts/` — demo contact payload; not persisted
- `GET /api/contacts/` — placeholder

Open `/docs` while the server runs to inspect the API.
